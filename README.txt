NIM JUNGLE 3D - FIXED STARTER PROJECT

1. Extract the whole folder.
2. Open the folder in VS Code.
3. Confirm Node.js is installed: node -v
4. Double-click start_windows.bat or run it from the VS Code terminal.
5. Open http://localhost:8000 in your browser.
6. Keep the terminal open while playing.

IMPORTANT:
- Keep index.html, style.css, main.js, server.js and start_windows.bat in the same folder.
- The 3D library (Three.js) is loaded from the internet via CDN, so internet is required.
- CSS declaration fixed: the original --shadow variable had a missing closing parenthesis.
